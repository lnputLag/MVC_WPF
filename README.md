# MVC_WPF

##  Описание проекта

**MVC_WPF** — это desctop приложение на **WPF**, демонстрирующее реализацию архитектуры **MVC** и использование популярных **паттернов проектирования**.  
Приложение позволяет работать с каталогом картриджей, выполнять авторизацию пользователей и демонстрирует интеграцию со сторонними сервисами (например, получение данных о погоде).

---

##  Основные возможности

- Авторизация и регистрация пользователей  
- Управление картриджами (добавление, редактирование, удаление, фильтрация)  
- Работа с моделями, типами и статусами картриджей  
- Создание объектов картриджей разных типов через **Фабрику**  
- Подключение к базе данных через **Singleton**  
- Получение данных от стороннего сервиса (**погода**)
- Сохранение с последующим открытием текста в формате txt через интерфейс программы (**заметки**)
- Реализация и подключение собственного стиля для sandbox
- SQL-скрипты для создания, очистки и наполнения базы тестовыми данными  

---

##  Архитектура проекта

Проект реализует трёхслойную структуру, разделяя ответственность между слоями:

| Слой | Описание |
|------|-----------|
| **Models** | Содержит классы бизнес-логики (`Cartridge`, `User`, `Supplier`). Для картриджей используется фабрика (`CartridgeFactory`) и иерархия наследования (`CartridgeBase`, `BWCartridge`, `ColorCartridge`, `RicohCartridge`). |
| **Controllers** | Управляют обработкой данных и логикой взаимодействия между моделью и представлением: `AuthController`, `CartridgeController`, `RegisterController`. |
| **Views** | Представления реализованы на XAML. Основные окна: `LoginWindow`, `RegisterWindow`, `MainWindow`, `NewCartridge`, `WeatherWindow`. |
| **Data** | Отвечает за работу с базой данных. Подключение реализовано через класс `DBConnection`, использующий паттерн **Singleton**. Запросы структурированы по папкам (`AuthUser`, `Cartridges`, `RegisterUser`, `SupplierQueries`). |
| **Helpers** | Вспомогательные классы для работы с формами, паролями, окнами и бизнес-логикой (`PasswordHelper`, `FormHelper`, `WindowCloseHelper`, `CartridgeHelper`). |

---

##  Используемые паттерны

- **MVC (Model-View-Controller)** — разделение логики на уровни  
- **Factory Method (Фабрика)** — создание объектов разных типов картриджей  
- **Singleton (Одиночка)** — используется в `DBConnection` для управления подключением к базе данных   

---

##  Интеграция со сторонними сервисами

В проекте реализован пример интеграции со сторонним источником данных — **получение информации о погоде**.  
Окно `WeatherWindow` демонстрирует, как можно подключать внешние API и сервисы, обрабатывая их данные в рамках архитектуры MVC.

---

##  Работа с базой данных

Для работы с базой данных в проекте предусмотрены SQL-скрипты (папка `SQL скрипты`):

- `Скрипт создания необходимых структур` — создаёт таблицы и связи  
- `Скрипт создания тестовых записей` — добавляет примерные данные  
- `Скрипт очистки всех данных` — очищает таблицы для повторного тестирования
